# Netflix Recommendation System

## Objective

Build a recommendation system using machine learning and content-based filtering.


## Dataset

Netflix Movies and TV Shows

Records: 8,807


## Data Cleaning

- Removed duplicates
- Handled missing values
- Converted dates
- Created new features


## Exploratory Data Analysis

- Movies vs TV Shows
- Release Years
- Ratings
- Countries
- Genres
- Directors
- Actors

## Feature Engineering

- Text Feature
- TF-IDF
- Label Encoding


## Machine Learning Models

| Model | Accuracy |
|---------|----------|
| Baseline | 69.6% |
| Logistic Regression | 99.03% |
| Naive Bayes | 96.36% |
| Decision Tree | 99.15% |
| KNN | 97.21% |


## Recommendation Techniques

- Content-Based Filtering
- Cosine Similarity
- Matrix Factorization (NMF)



## Deployment

Streamlit
